# 🛡️ Kathena Backend Server

대학교 중앙 게임 동아리 **Kathena**의 백엔드 API 서버입니다.

## 🛠 Tech Stack
- **Framework**: Spring Boot 3.x, Java 17
- **Database**: MySQL 8.0 (Data), Redis (Token/Cache, via Valkey)
- **ORM**: Spring Data JPA
- **Infra**: Docker, Docker Compose, GitHub Actions
